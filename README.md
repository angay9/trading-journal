# Trading Journal

A comprehensive trading journal application.

## 🚀 Features

- Track your trades with ease.
- AI-powered analysis (via OpenAI).
- Categorize and log your trading journey.

## 🛠️ Setup

1. Install dependencies (e.g., `npm install`).
2. Run the development server (e.g., `npm run dev`).
